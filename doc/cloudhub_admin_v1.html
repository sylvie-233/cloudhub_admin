组织管理

左侧选组织，中间维护岗位与汇报线，右侧查看该组织（含下级）的在岗用户

i组织不直接绑定用户。新建组织时自动生成「默认岗位」，每个组织只能有一个「责任岗位」，责任岗位上的在岗人即该组织责任人。岗位可设上级岗位形成汇报线，汇报线可跨组织。

权限管理

左侧选择授权对象（组织 / 岗位 / 角色），右侧勾选菜单与动作权限；角色另有数据权限配置

岗位 / 组织权限 角色权限

用户管理

用户只挂岗位，组织归属由岗位推导；最终权限 = 用户角色 ∪ 岗位权限 ∪ 组织权限

最终权限 = 用户角色 ∪ 岗位权限 ∪ 组织权限

角色管理

左侧选择角色，右侧维护该角色下的用户；角色只授予用户，菜单权限与数据范围随角色生效

菜单管理

目录 / 菜单 / 动作 三级结构，动作权限标识即后端鉴权点

权限标识建议遵循 模块:实体:动作
